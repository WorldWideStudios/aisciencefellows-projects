# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/0dfbfa9a-2184-4c8c-b8e5-357ad6a59271

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Open the app and paste your Gemini API key into the key field (get a free key at https://aistudio.google.com/apikey). No server-side API keys or environment variables are needed — each user brings their own key, which is stored only in their browser.
