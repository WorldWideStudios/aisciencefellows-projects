# Printable sorting hardware (concepts for visual review)

Generated by `python -m baebugs.print_parts` (parametric: edit `P` in `baebugs/print_parts.py`).
Every part is watertight; nothing here is calibrated or tested on specimens. Printed holes are not
calibrated apertures: measure them before use (and see `baebugs/inserts.py` for the stainless route).

| Part | Qty | Notes |
|---|---|---|
| `trommel_zone_2mm`, `_4mm`, `_7mm` | 1 each | 110 mm drum, 70 mm zones, swappable/reorderable; spigot joints; 3 low lifter ribs |
| `trommel_cap_inlet`, `trommel_cap_outlet` | 1 each | spoked hubs on an 8 mm rod, M3 set screw; feed between the spokes, oversize leaves the outlet |
| `trommel_stand_inlet`, `trommel_stand_outlet` | 1 each | 608 bearing pockets; inlet stand is 12 mm taller (3 deg incline) |
| `trommel_crank_hand` | 1 | hand-crank demo (no motor needed) |
| `trommel_crank_arm` | 1 | knob with parallel flats (20 mm jaw gap) + V-grooves so the robot arm can turn the drum |
| `trommel_bin` (x3), `trommel_bin_oversize` | 4 | ArUco/AprilTag pocket on the front (camera scale + identity), 2 x M3 for the grip handle |
| `vortex_puck_76` | 1 | presses into a 3 in vortexer platform; socket for the mini stack; rubber-band hooks |
| `vortex_mini_sieve_1.5/3/5mm`, `vortex_mini_pan`, `vortex_mini_lid` | 1 each | 50 mm stackable rings (coarse on top) |
| `centrifuge_tube_strainer_1.5/3mm` | 1 each | sits in a 50 mL conical tube mouth; cap off; slow spin only |
| `arm_grip_handle` | 2+ | bolts to bins/lids (2 x M3, 20 mm spacing); jaw flats + V-grooves; 14 mm tag pocket |

**Hardware:** 8 mm steel rod ~320 mm, 2 x 608 bearings, M3 x 8 set screws (4), M3 x 10 screws + nuts, rubber bands, printed ArUco tags.
**Print:** PLA/PETG or Fuse 1+ PA12; zones print upright (holes radial, no supports for 2-4 mm; 7 mm may bridge).
**Check first:** your vortexer platform diameter (`vortex_platform_d`), your arm's jaw opening (`jaw_gap`), your centrifuge rotor
(buckets must take open 50 mL tubes) and rod/bearing sizes. Change `P` and regenerate.
Previews: `previews.png`, assembly: `trommel_assembly.png` / `trommel_assembly.glb`.
