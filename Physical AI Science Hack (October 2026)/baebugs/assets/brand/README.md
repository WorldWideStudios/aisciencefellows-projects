# baebugs brand

`baebugs_mark.svg` / `_dark`, `baebugs_logo.svg` / `_dark`, PNG renders and `favicon_64.png`, generated by `python -m baebugs.brand`.
Original artwork, MIT (repository licence). The wordmark is outlined from **Bricolage Grotesque** (SIL Open Font License 1.1),
which permits embedding outlines in a logo; the font itself is not redistributed. `options/` holds four alternative concepts from a teammate.
