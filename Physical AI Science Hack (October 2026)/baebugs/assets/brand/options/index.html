BaeBugs logo options

Four first-pass marks, all built from one shape: a ladybug whose shell is a heart. Each row shows the mark on light and dark, a wordmark lockup, and favicon sizes. Comment on the PR with a letter (or "A, but with B's spots"). The current repo logo in ../ stays the default until a pick is made.

Production notes. Every mark is flat vector, at most four colors, no gradients, so it works as a favicon, a sticker, and a single-colour emboss on a printed tube rack (option D is the one-extrusion version). Wordmark text uses Fredoka; I'll convert it to outlines when we pick, so the SVG renders without the font.
