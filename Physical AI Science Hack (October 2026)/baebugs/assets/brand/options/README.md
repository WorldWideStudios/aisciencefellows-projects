# Logo options (for teammate review)

Four alternative BaeBugs marks: a cute bug with a heart. Open `index.html` in a browser to compare them on light and dark, as wordmark lockups, and at 16/32/48 px favicon sizes.

| Option | Idea | Files |
|---|---|---|
| A, Heartbug (recommended) | Heart-shaped shell, face in the notch, heart-tipped antennae | `option_a_*` |
| B, Heart-spot beetle | Round ladybug with heart-shaped spots | `option_b_*` |
| C, Specimen badge | A inside a petri-dish ring, "open science · virtual lab" | `option_c_*` |
| D, Monoline | One colour, strokes only, for etching or a single-extrusion emboss on printed labware | `option_d_*` |

Each option has `_mark.svg`, `_mark_dark.svg`, `_logo.svg`, `_logo_dark.svg` (wordmark) and `_favicon.svg` (simplified 32 px glyph).

These do not replace the logo already in `assets/brand/` (built by `baebugs/brand.py`). Once the team picks, the winner gets folded into `brand.py` and its wordmark outlined, since these `_logo` SVGs still reference the Fredoka font by name.
