Per-taxon preprocessors route a bug to the model that knows it

Data

2,627 specimen crops: 2,015 train (CA), 381 val (CA), 231 test (AZ, NV, OR). Media-id leakage: 0.

Design

An ORDER router, then a FAMILY model inside Hymenoptera and Diptera. Small yolo11n-cls models.

Rule

USEFUL only if test macro-F1 beats the majority baseline by more than 0.10.

0.70

ORDER router, out-of-state test macro-F1, vs 0.135 majority baseline: USEFUL.

Final v4 result, test top-1 0.948 on 231 crops; full table on the next slide.

The idea: each taxon gets a highly trained small model that preprocesses for lower or local models, so a local model only sees the taxa it is specialised for.
