# Sieving demo (animated simulation)

`sieving_demo.mp4` is a 63 s animated concept demo of the camera-guided sieving workflow with an SO-101 arm and two 3-ledge shelves (dimensions taken from `shelf.STL`: 130 x 110 x 304 mm).

**This is a simulation, not footage of real hardware.** Purity values (80% then 96%, target 95%) are illustrative and were not measured.

Re-render: `python3 render_demo.py render` (needs numpy, opencv-python, pillow, ffmpeg, DejaVu fonts). Writes `sieving_demo.mp4` in the current directory.
