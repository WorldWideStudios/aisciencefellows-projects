## Product direction and best practice

Use a constrained component configurator first. A free-form AI agent can later propose a configuration, but a deterministic compiler should validate it against available equipment, measured compatibility, model/task fit and release gates. A purely autonomous robot composer is premature without those receipts.

The new page is an implemented local draft builder: known specimen or search objective → component selection → seven vision checkpoints → downloadable JSON protocol. It references existing modules; it does not execute those modules, perform AI inference or control hardware. A natural-language objective is captured, not semantically interpreted. Arbitrary model/component plugins and compatibility solving are PROPOSED.

Every handoff must bind sample/specimen occurrence, input image, calibration, model/version/output, human decision, physical action, observed output and destination. Prediction and observation remain separate. Add non-vision sensors where needed: cameras cannot establish temperature or successful chemistry. Disagreement, missing calibration, uncertain identity and incompatible components must block execution rather than silently select a plan.

Remix means compose adapters with task schemas and source/license references; it does not mean copy every upstream model. Preserve existing third-party terms. Measure specimen-disjoint detection/segmentation, counting error, recovery, damage, pick success, well mapping and abstention separately. Keep failed and negative trials in the notebook and ledger.
