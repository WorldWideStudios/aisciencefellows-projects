# @biobitworks/baebugs-aok (repository-local)

An offline read-only CLI for a bounded public Baebugs evidence snapshot.
No npm registry release has been performed. Run `npm pack ./packages/baebugs-aok` only after copying the currently verified `site/aok/data/*.json` into `packages/baebugs-aok/data/`.
