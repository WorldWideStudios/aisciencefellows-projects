# 2026 AI Science Fellowship — Final Demos

Final demo projects from the Science fellows. Each folder is a **point-in-time snapshot** of
the fellow's project repository (its `.git` history is stripped, so these are frozen copies,
not live submodules). For the latest version of any project, follow the GitHub link. Pitch
decks live in [`slides/`](./slides).

Several of these projects also appear under `Week 1`–`Week 4`; those are earlier snapshots of
the same work.
