📋 Interpretation Notes Compound mismatch: The 9 test compounds dispensed were entirely different from the workflow plan. The raw plate data is valid; only the labels were wrong. This report uses corrected identities.
Narrow dynamic range: A_vehicle − A_no_enzyme ≈ 0.038 AU — noise-limited. Use initial velocity (slope) as the primary activity metric.
All 9 compounds are TEM-1 substrates: Cefpiramide, Ceftiofur, Cephradine, Cefadroxil, Cephalexin are cephalosporins; Amoxicillin is a penicillin — all cleaved by TEM-1. Methicillin, Dicloxacillin, Cloxacillin are semi-synthetic penicillins with some resistance to β-lactamases.
Positive control worked: Clavulanic Acid 1 µM shows the lowest slope (0.18 mΔA/min vs 5.26 for vehicle), confirming the assay detected inhibition.
Next steps: Re-run with the intended compounds (Tazobactam, Sulbactam, Enmetazobactam, Meropenem, Oxacillin, Cefazolin) from the correct source wells. Increase nitrocefin to widen dynamic range.
