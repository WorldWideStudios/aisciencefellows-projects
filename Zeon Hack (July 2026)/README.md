# Zeon Hack — July 2026

Team projects from the Zeon hackathon (July 2026), where teams built lab-automation and
self-driving-lab workflows on the Zeon robotics platform.

Each folder is a **point-in-time snapshot** of the team's project repository (its `.git`
history is stripped, so these are frozen copies, not live submodules). For the latest version
of any project, follow the repo link. Pitch decks live in [`slides/`](./slides).
